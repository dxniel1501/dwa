# Survival Addon (Meteor Client, Minecraft 1.21.11)

Module (Kategorie "Survival"):
- `interact-freecam`: mit Meteors Freecam Bloecke in Spielerreichweite abbauen/benutzen
- `activity-finder`: Chunks mit ausgewachsenen Amethyst-Clustern, Kelp und rotiertem Deepslate markieren
- `nametag-plus`: eigene Spieler-Nametags (Format, Aliase, Ping, Distanz, Gamemode, Item)

## .jar bekommen
1. Alle Dateien dieses Ordners in ein eigenes GitHub-Repo hochladen (auch den Ordner `.github`).
2. Warten, bis unter "Actions" der Build gruen ist.
3. Rechts im Repo auf "Releases" -> "Dev Build" -> die `.jar` herunterladen.

## Installieren
`.jar` + Meteor Client 1.21.11 + Fabric API in den `mods`-Ordner einer Fabric-1.21.11-Instanz.

Hinweis: Nicht lokal kompiliert. Bei Build-Fehlern die Zeilen mit "error:" an Claude schicken.
